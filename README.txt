PARA ALEJITA — EDICIÓN PREMIUM MULTIPÁGINA

PÁGINAS INDEPENDIENTES:
- index.html          Inicio
- dedicatoria.html    Dedicatoria
- cualidades.html     Cualidades
- carta.html          Carta personal
- sorpresa.html       Sorpresa interactiva

RECURSOS COMPARTIDOS:
- css/style.css       Diseño visual premium y responsive
- js/script.js        Menú móvil, animaciones y sorpresa
- img/                Carpeta para imágenes propias

USO:
1. Extrae el ZIP completo.
2. Abre la carpeta Para_Alejita_Pro en Visual Studio Code.
3. Abre index.html con Live Server.
4. Mantén la estructura de carpetas para que todos los enlaces funcionen.

El sitio incluye navegación entre páginas, menú móvil, diseño responsive, animaciones suaves y estilos compartidos.
Las fuentes de Google se cargan con internet; hay alternativas locales si no están disponibles.
